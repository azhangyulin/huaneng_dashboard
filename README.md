# 华能国际 2025年全年上网电量 - 大数据看板

> 华能国际电力股份有限公司 2025 年度各省上网电量可视化仪表板

基于 ECharts 构建的数据可视化大屏，展示华能国际 2025 年全年在全国各省份的上网电量分布。

## 📊 功能

- 🗺️ 中国地图 + 各省份上网电量热力分布
- 📈 月度电量趋势图
- 📊 各省份电量排名
- 🏭 按发电类型（火电/风电/光伏/水电/其他）分类统计

## 🚀 使用方式

直接在浏览器中打开 `huaneng_dashboard.html`，或部署到任意静态文件服务器。

## 📁 文件说明

| 文件 | 说明 |
|------|------|
| `huaneng_dashboard.html` | 主页面 |
| `echarts.min.js` | ECharts 图表库 |
| `china_geojson.json` | 中国地图 GeoJSON 数据 |
| `huaneng_dashboard.png` | 预览截图 |
